# Quality gates

Each stage must pass a review before its outputs become inputs to the next stage.

| Gate | Review questions |
|---|---|
| Inputs | Is the source identifiable, dated and permitted for the intended use? |
| Variables | Are original facts preserved? Are interpretation and filtering documented? |
| Mapping | Does each relationship have a written rationale? Are important signals orphaned? |
| Evolution | Does every continuity or change claim cite comparable evidence? |
| Visual review | Are observations separated from inferred material properties? Are repeated appearances independent? |
| Theme development | Do themes cover the intended categories without duplicating one another? |
| Story output | Is the language specific, product-relevant and consistent with the evidence? |

## Suggested confidence rubric

Use project-specific thresholds instead of treating these defaults as universal truth.

- `emerging`: repeated in at least two independent sources; requires further validation.
- `developing`: repeated across several sources and product examples; boundaries are reasonably clear.
- `established`: broad independent repetition with a coherent cross-season trajectory.

The number of images alone does not determine confidence. Source diversity, sample bias, category relevance and human review all matter.
