# Data, copyright and ethics

This public repository contains only original framework documentation and synthetic examples.

## Excluded by design

- Licensed trend-report text, scores, charts, images and colour selections
- Runway photographs and scraped image collections
- Company names, internal product codes, supplier information and commercial strategy
- Client briefs, unpublished research and identifiable project data

## Safe adaptation checklist

Before publishing a real implementation:

1. Confirm that every source may be redistributed.
2. Replace licensed or confidential inputs with citations, metadata or synthetic examples.
3. Separate observed facts from visual inference.
4. Record the reviewer and review date for consequential conclusions.
5. Check that generated summaries do not reproduce protected source language.

The framework supports research governance; it does not grant rights to underlying data.
