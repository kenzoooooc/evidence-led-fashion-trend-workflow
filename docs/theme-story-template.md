# Eight-module theme story template

## 1. Core narrative

One concise paragraph connecting style, silhouette, material character, handfeel and colour. Avoid poetic filler and unsupported specifications.

## 2. Silhouette language

List precise garments and the intended volume, proportion, shoulder and length.

## 3. Pattern direction

Describe specific stripes, checks, jacquards, prints or textural pattern effects.

## 4. Material direction

Translate the evidence into brand-appropriate material language. Separate confirmed composition from desired character.

## 5. Evidence

Reference the supporting signal IDs, observation IDs and confidence level.

## 6. Consumer rationale

Explain why the relevant needs and mindsets support this theme.

## 7. Colour range

Specify roles such as foundation, supporting and accent colours. Use proprietary colour codes only when publication rights allow it.

## 8. Reference set

List permitted references or internal asset IDs. Do not include unlicensed imagery in a public repository.
